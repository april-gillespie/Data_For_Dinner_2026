# Team report package

- `Data_for_Dinner_Food_Access_Analysis.docx`: editable team report.
- `Data_for_Dinner_Food_Access_Analysis.pdf`: fixed-layout version of the report.
- `Data_for_Dinner_Food_Access_Analysis.xlsx`: 15-sheet source, data, sensitivity, QA, assessment, variable, and team-story guide workbook.

The report answers the current food-access question without adding allergies to the active analysis. Feeding America Map the Meal Gap 2026 is included as a separate modeled Alabama county and state outcome layer. Sandra Kopecky's contributed workbook is credited as the prevailing team story source, while the validated analysis workbook remains the audit source for exact claims. The allergy feasibility recommendation and reusable prompt appear in both the report and `docs/allergy_next_crawl.md`.

All three files were rendered and visually checked. The DOCX accessibility audit reports zero high-, medium-, or low-severity findings; the workbook formula-error scan reports zero matches.
